run

()
static

[ BROWSER ONLY ]

Compile each jipl script within the page. jpx-jipl scripts must have type text/jpx-jipl.

Example

    <script type="text/jpx-jipl">
        var I = new jpx.Image('my/super/image.jpg', function()
        {
            foreach(pixel p) in this
                var i = p.index;
                var d = @data[i];
                @data[i] = d / 2;
            /foreach
        });
    </script>
    <script>
        jpx.jipl.run();
    </script>
